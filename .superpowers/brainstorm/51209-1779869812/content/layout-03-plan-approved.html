交互含义

Plan 是未来日期的时间线编辑器。AI 规划后，任务会按优先级、预计时长和 memory 被排入时间线；没有时长的任务会被初始化一个建议时长。

主动作底部只保留“AI 规划”。规划后通过动画把任务放入时间线，并把放不下的任务留在底部。
手动控制用户可以拖拽任务进入时间线、移除时间线、重排顺序；允许任务并排放置。
消息入口AI 建议和夜间酝酿进入右上角 message inbox，点击后以 pop-out window 展示和处理。
