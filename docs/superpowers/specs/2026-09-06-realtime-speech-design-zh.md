# 助手实时语音输入

2026-09-06，用户已选择 Fun-ASR 实时版，并确认边说边转写、主动点完成后交给 AI。

## 本轮实现范围

- 助手输入框新增麦克风。开始后显示实时文字；停顿不会提交。
- 点击“完成”停止采集，排空已采集音频，发送 finish-task，等待 task-finished 后将最终逐字稿一次提交给当前助手会话。
- 中间转写按句子 ID 替换；已定稿的句子不会被迟到的中间结果覆盖。
- 连接中、录音中、收尾中状态明确；取消、离开助手、切换会话或进入后台均停止录音，取消后不会提交。错误时保留已显示的文字供修改。
- 阿里云语音独立配置。用户自行输入/粘贴百炼 API Key，设备安全存储；不内置共享 Key，不写日志或任务快照。采用北京区 fun-asr-realtime、16 kHz 单声道 PCM。
- 只在用户启动语音后申请麦克风权限并发送音频。录音不永久存档。

## 边界

本轮接通语音到现有助手。前序已讨论的 AI 直接修改日程、高亮、整次撤销、可选确认，以及 Markdown 同步和使用 trace 是后续独立改动；本轮不会把现有计划确认流程误标为已经替换。

## 验证

覆盖中间稿修订、定稿保护、多句累积、迟到事件隔离、收尾后一次提交、取消不提交、错误保留草稿；运行 Swift 包检查、iOS 编译和相关自动化测试。真实百炼接口已使用同一段 100 秒录音验证，但手机麦克风实际体验仍须以真机验证为准。

验收记录：[实时语音输入验收](../../qa/2026-09-06-realtime-speech-acceptance.md)。

## 2026-09-07：可切换的苹果原生识别

用户同意同时保留两种识别方式供试用。助手的语音设置新增“苹果原生 / 阿里云 FunASR”，保存选择；已有安装默认仍为 FunASR，切换不删除已有密钥。

- 苹果路径使用 iOS 26+ SpeechAnalyzer / SpeechTranscriber 中文端侧模型。首次使用检查硬件、语言和模型资源，必要时下载，显示准备状态；不支持时给出明确说明，不自动把音频发往云端。
- 设置页可提前准备中文模型；苹果路径不要求语音 API Key。语音只在设备处理，完成后的文字仍会交给现有聊天 AI。
- 两种路径一致：实时草稿、主动点完成、等待定稿、只提交一次。取消、后台、离开或切换会话不提交，失败保留文字。
- 本轮不改动今天、旧计划页的 SFSpeechRecognizer，也不更改现有 AI 写入确认规则。
- 验证分为生命周期自动化、设置切换 UI、苹果真机可用性与识别质量；编译通过不代表中文质量通过。

切换功能验收：[苹果原生 / FunASR 切换](../../qa/2026-09-07-apple-speech-switch.md)。

苹果实时路径开启 volatileResults + fastResults：直接音频真机测试确认只开启 volatileResults 会延迟到收尾才出字。fastResults 通过较短上下文降低延迟，质量仍需按关键语义和自然口述验收。

后续真机验收：[苹果与 FunASR 真机对比](../../qa/2026-09-07-speech-comparison.md)，已验证苹果模型与双方麦克风到 AI 链路。

## 2026-09-08：输入区切换与 FunASR 录后转写

用户要求简化听写切换，FunASR 不再实时出字。本节替代上文 FunASR 边录边上传的交互；苹果原生仍保留实时草稿。

- 输入框旁常驻当前识别方式菜单，直接切换苹果原生/FunASR，并可进入语音设置；移除右上角更多菜单中的重复语音入口。录音、转写或待重试期间不允许切换识别方式。
- FunASR 只在本机暂存本段 16 kHz 单声道 PCM；录音时展示时长和 5 分钟上限。点完成后封装 WAV，通过非实时 HTTP 接口上传，完整文字返回后按既有流程提交 AI。不是隐藏实时字幕，也不继续使用 WebSocket。
- 采用官方 Fun-ASR-Realtime 非实时模式，关闭 SSE，Base64 音频直传，不新增 OSS 或其他云存储配置。模型标识保留 fun-asr-realtime，但调用协议和交互为非实时。
- 满 5 分钟停止采集，显示已达上限，等待用户点完成；不自动提交。上传失败只在当前会话内存中保留本段音频，允许重试/放弃；取消、切会话、后台或离开页面清理暂存，迟到结果不能提交。录音不落盘。
- 验证录音期间零网络请求、一次完成只提交一次、取消和旧请求隔离、失败重试保留全部音频、时长上限，以及输入区切换持久化与实际 UI。

接口依据（2026-09-08 核对）：https://help.aliyun.com/zh/model-studio/non-real-time-speech-recognition-for-fun-asr-realtime ；音频规格：https://help.aliyun.com/zh/model-studio/asr-model 。
