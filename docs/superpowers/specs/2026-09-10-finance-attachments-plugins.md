# 理账计划、附件与功能插件

延续用户已确认 UI / schema / AI / Trace 分层。本轮需求包括订阅、待付账单、信用卡/房租/订阅/借款还款提醒与话术、预算联动、附件及可加载功能模块。

## 理账闭环

新增财务计划（订阅、账单、信用卡、房租、借款还款），含金额/币种、下次到期日、一次/每月/每年、提前提醒天数、可编辑提示话术、可选应用URL、附件ID。订阅仅作为计划，不自动写实付账单。用户点“已支付并记账”，原子写入同一 Capture ledger 及支付回执，循环计划推进到下期；重试幂等，可撤销最近一次支付且避免覆盖后续修改。信用卡还款及借款本金默认为 transfer，不重复计入消费；用户可选择 expense（租金/订阅）或 income。提醒仅本地通知，不执行支付或自动联系他人。自定义URL为用户点击时打开，拒绝 file/javascript/data 等敏感scheme；HTTPS作为稳定入口。

预算按月、币种、可选分类统计既有 ledger 实际 expense；不混币种、不计 transfer。预算、已花、剩余/超支联动，分类合并后使用归并后的分类关系。

## 附件

随手记与财务计划共享不可变文件附件库，保留原文件名、扩展名、hash与字节数。图片和PDF首屏缩略图，不能渲染的文件显示扩展名/icon；点开系统预览或分享原件。文件最大25MiB，单次最多10个；附件保存失败不清输入。附件不因预览而上传AI，只有现有明确整理动作会使用可识别文字。兼容旧快照。

## 插件

先实现声明式插件：内置今天、任务、助手、回想、随手记、理账、财务计划、预算、导入、语音/附件及同步/trace功能均注册到manifest，管理页启停、说明依赖，停用保留数据。第三方JSON插件能声明输入字段、模板及显式跳转；安装时预览能力，调用统一Capture保存命令，不能直接改快照。shell与管理入口永远可达。脚本执行作为另一个明确能力阶段，不冒称任意Obsidian插件能在iOS运行。

## 验收

Core测试覆盖循环月底/闰年、重复支付、撤销、预算币种/转账、旧快照；App/UI测试覆盖录入订阅、附件缩略图、预算联动、启停/重新启用、manifest加载，构建并尝试真机安装。实际通知送达、外部应用安装状态分别报告。
