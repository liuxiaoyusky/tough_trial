# 独立转录库：文件转录与摘要优先

状态：用户已确认评审稿；2026-09-25 开始实现。

## 目标与入口

`转录`是独立、可搜索的本地记录库，默认出现在「更多插件」，也可加入底栏。关闭模块不删除已保存记录。每条记录保留原音频或视频、来源文件名、识别方式、逐字稿和自动摘要；不写入随手记或日程同步。

## 导入与处理

- 从文件选择器导入录音或视频，从相册选择视频。iOS 注册音视频文档类型，系统把“在 Tough Trial 中打开”的共享文件交给转录库；若某个来源应用不显示该系统操作，仍可经「存储到文件」导入。独立分享扩展是后续范围。
- 导入时复制原文件到 App 本地目录，建立草稿；识别失败或离开页面时仍保留原文件和已完成的文字。
- 苹果原生识别使用 iOS 26/macOS 26 SpeechAnalyzer 中文模型，设备不支持时给出明确提示。FunASR 沿用已保存的百炼语音密钥，把音轨转为单声道 16 kHz PCM，按不超过 5 分钟的片段提交，清楚告知上传音频与可能的服务费用。每个片段完成后保存结果；重试只处理未完成片段。
- 用户可以选择识别方式。转录完成后，若已配置 AI 服务，自动将逐字稿发送到该服务生成摘要；未配置或摘要失败时，逐字稿仍可用，并提供重试。开始前告知这一步的数据流。

## 展示与数据

- 转录库列表先显示摘要片段，再显示来源与识别状态；搜索覆盖标题、摘要和逐字稿。搜索结果能打开对应记录。
- 记录页先显示可编辑摘要，再显示完整逐字稿入口。完整逐字稿可编辑并播放原媒体。转录进行中暂时禁用摘要 / 逐字稿编辑与摘要重试，说明暂停后可编辑；摘要生成期间禁用摘要编辑，防止异步写入覆盖手工内容。摘要基于转录文字，不能把建议事项自动写进任务或日程。
- 数据先只在本机保存；当前 GitHub 日程同步不包含转录库。删除记录及原文件须由用户明确操作。

## 验收边界

评审站 `outputs/transcription-design-review/` 是静态设计参考，不代表 App 功能已完成。实际验收需检查导入、两种识别、暂停/重试、摘要失败、搜索、编辑和重启后读取；若设备或服务不可用，记录未覆盖的真实路径。
