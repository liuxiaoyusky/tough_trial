# 助手主页重做

用户于 2026-09-11 确认 docs/roadmap.md P0–P5 并要求推进。本规格覆盖旧助手独立全屏入口和关键词路由行为，业务数据/账单确认/撤销规则保持。

- 默认助手 Tab；顺序助手、今天、任务、随手记、回想。正常助手不全屏；来源任务通过 Tab 跳转并携带引用。插件隐藏时保留可达的临时入口。
- 输入支持长文本滚动及同页展开编辑，按会话保存草稿和引用。展开只增高当前输入区，保留会话消息和上下文；收起后继续使用同一草稿，不跳转到脱离对话的编辑页。输入区在明确高度范围内内部滚动，录入时跟随光标，用户手动回看时不抢回滚动位置；输入法组合文本原样保留。双方消息可复制、选择、引用；引用携带会话/消息 ID 和文本快照进入请求，不仅展示卡片。
- 通用个人助手默认自由对话；已注册领域功能通过工具调用。语义判定绑定当前轮和实际用户输入，保留宿主 schema、事务、权限和确认规则；不能从旧错误/问候恢复写授权。
- 会话可覆盖服务、模型、thinking，切换下一轮生效。仅展示供应商模型实际支持的参数，不伪装统一档位。
- Compact 必须有实际缩减且提供前后字符规模、来源和摘要；短会话/重复无收益不提示成功。原文不删，引用独立保存。
- 进行中允许编辑补充输入；补充作为明确的新用户请求排队，展示状态且可撤回。已经提交的业务操作不受后续补充追溯修改。
- 验收长输入、引用真实入参、切 Tab 草稿、跨重启、配置映射、上下文缩减、否定/问候/口语及工具连续调用。真机连接时安装启动，无法连接如实记录。

## 实施中的明确边界

- 原生输入与消息工具已实现；文件按现有附件规则本地保存，文本/PDF/OCR 文字作为引用，不声称完整视觉模型上传。
- 未被宿主明确识别的口语修改，由模型生成提案并强制人工确认；不再直接误拦截，也不把模型判断等同于自动写权限。
- Compact 为有来源的本地摘录摘要。比较实际历史正文 + 摘要；固定引用、本轮输入和工具结果单独传递，token 估算不冒充服务商计费值。
- GLM5.3/Flash 按当前官方接口要求始终思考，低强度为默认。正在生成的回答和工具子调用固定相同配置。

## MiniMax 海外配置修复

- 新配置默认海外站，设置里只需选择“海外 / 国内”和填写对应站点的 Key，无需填写 URL。保存保留所选地址，不强制回到国内。
- 已保存配置保持原站点，不能从 Key 外观猜测地区，也不能认证失败后自动跨地区尝试。当前用户明确使用海外 Coding Plan，可定向纠正其设备上的错误地址并复用已有 Key。
- 用隔离的合成消息进行真实接口验证；不重发私人对话。

## 配置连接测试

- 配置页统一提供“测试连接”和“保存配置”。测试使用当前未保存的服务、地址、Key、模型和思考参数，发送独立合成消息，不读写用户会话或业务数据。
- 当前配置测试成功后才能保存；改变任意配置或切换服务会使验证失效，过期异步结果不得启用保存。测试失败不覆盖现有配置。
- 错误区分鉴权、网络、限流与回复格式，密钥不进入错误提示。工具调用的旁白字段可忽略，与原生 tool_calls 处理一致；执行仍只使用指定工具及其 arguments 并经宿主 schema/授权校验。

## 2026-09-11 工具续接契约补充

注册工具统一走原生 function calling；文字回答只展示，旧 JSON 操作作为兼容解码保留。每次原生调用后须把 assistant tool_calls 与逐条对应的 tool 结果回传模型，供应商要求的续接字段仅在当前轮次内存中保留，不写入日志。批量调用先统一校验，再顺序执行；遇到确认、失败或取消等停止状态，不执行剩余调用。

连接成功与助手流程验收分开：前者只证明配置可用；后者必须验证依赖工具结果的连续调用及实际数据结果。当前证据和覆盖边界见 `docs/qa/2026-09-11-assistant-tool-continuation.md`。

## 2026-09-11 口述待办与任务卡片

用户确认：任务卡片展示整理出的任务，操作按钮触发下一步。口述列出今日待办应生成结构化任务提案，不能只复述内容或泛问“创建任务还是排顺序”。缺少具体钟点不妨碍整理当天待办；细节进入备注，不应丢弃。未满足宿主自动写入权限时展示待确认卡片，确认后共用今天/任务的数据记录。

原生日程工具与既有日程入口统一到同一提案、确认和撤销流程。新增任务按任务聚合展示，创建与排期不拆成两张卡片；状态区分待确认、已保存、已撤销、已取消。待确认任务可编辑标题、备注和日期，编辑只修改提案；保存后可通过带任务引用的助手继续调整。

能力流程说明由当前启用工具目录生成，涵盖触发场景、调用流程、输出卡片和确认约束；参数 schema 仍从唯一工具注册表输出。此次先落实任务流程，不建立任意外部脚本执行或独立业务数据格式。

## 任务卡片点击语义补充

已保存且仍存在的任务，左侧复选框是直接完成/恢复待办按钮，使用与今天相同的任务和排期状态，不调用 AI。待确认卡片只显示序号，不显示伪复选框。已撤销/取消卡片不提供完成动作。完成与恢复在助手和今天保持一致；完成操作有宿主回执，恢复刚才的完成可还原此前状态，之后仍可撤销最初创建。

此次任务卡片验收须实际点击：编辑、编辑取消/完成、日期开关和选择、确认/取消、完成/恢复、调整取消/发送、整次撤销，并核对反馈与业务状态。

## B 批次键盘收起

长输入在原框内滚动。输入区提供明确的“收起键盘”按钮，结束焦点后恢复底部页面切换，保留文字和引用。输入组件直接绑定编辑器焦点，展开与收起仍不更换草稿。小屏在键盘和操作行可见的前提下限制展开高度。
