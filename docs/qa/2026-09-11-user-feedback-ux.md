# 用户反馈体验修复 A 批次验收（2026-09-11）

范围：共用任务新增/编辑组件、任务详情与结构列表完成/恢复/撤销、时间/鱼骨详情入口。B 的语音与其他编辑器迁移、C 的分类/记账、D 的联网不属于本批实现。

## 实现与数据边界

- `Components/Tasks/V2TaskEditor` 在任务页结构/鱼骨新增和已有任务详情中共用；同容器编辑标题、备注，空标题禁用，取消有改动时确认放弃，保存失败保留草稿。
- 详情 medium/large 可拉高，导航与底部操作常驻；路径只显示祖先。结构列表叶任务圆圈为独立完成按钮。
- 时间选中任务可进入同一详情；全天多项的数量入口提供完整选择菜单；鱼骨任务节点可进入同一详情。
- 编辑以稳定 ID 和原对象基线保存；过期/归档目标拒绝覆盖。当前任务视图显示最新标题，原始排期及执行记录保留。
- 完成/恢复原子更新任务及当天全部非取消安排，有持久回执可撤销。未来安排不改，不批量完成子任务，不自动结束计时；详情显示计时提示。撤销有后续修改时拒绝覆盖。
