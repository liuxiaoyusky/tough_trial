# 六层结构实际观感验收

2026-09-21；用户请求验证六层，并询问倒树布局的可行方法。

## 范围与结果

- 仅增加 DEBUG 专用合成数据入口及 UI 测试；不改变正式布局、不写入个人任务。
- iPhone 17e / iOS 26.5 模拟器，390 点宽、默认字号与 100% 比例；1 个用例通过，18.583 秒。
- 六层深链，另加根下同级分支和第二棵树，共 8 个节点。默认展示前三层；逐层实际点击展开三次。
- 第六层长标题两行可见，按钮边界在屏幕内，无需横向滚动。展开后旁支下移超过 150 点；收起后回到原位置，误差不超过 2 点。
- 深层标题点击打开正确详情；关闭、向下滚动、第二棵树可达、重置、收起均通过。
- 已人工查看展开与滚动截图：层级清楚，但深层左侧缩进占用 120 点，旁支连线会随子树增长而变长。此次不是每层多分支的高密度压力测试，也未覆盖大字体/六层真机。

## 倒树讨论（未实现）

“倒树”可能指根在下、枝向上，也可能指根在上、向下分叉的组织图。两种都可复用任务关系，仅替换布局。手机建议用聚焦子树、折叠旁支和固定当前节点位置控制宽度；展开时自动移动周围节点，但避免正在操作的节点跳走。不能单纯将截图翻转，否则文字与点击位置也会错位。
