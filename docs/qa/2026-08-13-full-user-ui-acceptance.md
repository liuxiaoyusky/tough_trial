# Tough Trial 完整用户 UI 验收报告

- 日期：2026-08-13
- 被测分支：`codex/public-release-ready`
- 验收对象：当前工作区中的 Tough Trial SwiftUI iOS App
- 依据：`docs/spec.md` 与 `docs/superpowers/specs/2026-05-30-tough-trial-interaction-redesign-design-zh.md`
- 结论：**不通过完整 spec 验收；当前版本可作为内部体验版继续使用**

## 结论摘要

应用可以启动，四个主入口可达，现有 UI 自动化在 iPhone 17e 上 8/8 通过，第二种 iPhone 尺寸的代表性视觉与任务地图用例 2/2 通过；补充的隔离用户旅程也验证了今天执行闭环、并行会话、本地计划对话确认，以及任务和回想内容跨重启恢复。两个核心检查和完整 Swift Package 构建同样通过。没有发现启动崩溃、主导航断裂或明显遮挡。

但当前版本仍有 3 个 P1 级核心路径缺口：默认任务结构页的新增按钮不能创建任务、任务节点没有 `AI 计划` 入口、空状态不能启动未关联 Zen。这三项直接切断了“看见任务 -> 安排任务 -> 执行今天”的产品闭环，因此不能判定与当前文字 spec 一致。

## Findings

### P1-1 任务结构与鱼骨视角的新增按钮没有新增能力

- 页面：`任务`
- 预期：点击右下角加号后，在当前结构卡片或当前上下文创建任务 / 节点；鱼骨视角也应提供可完成的轻量捕获路径。
- 实际：只有时间视角会显示可输入、可提交的新增面板。结构和鱼骨视角点击加号只显示“在当前视角轻记一笔”，没有输入框、提交动作或 durable-data 写入。
- 复现：打开 `任务` -> 保持默认 `结构` -> 点击右下角 `+`；切到 `鱼骨` 后重复。
- 证据等级：C，源码与 spec 审计。
- 证据：`V2TasksView.swift:111-157`；spec `270-288`。
- 影响：用户在默认主视图看到明确的新增按钮，却无法完成新增，属于主路径死入口。

### P1-2 任务节点没有轻量详情与 AI 计划入口

- 页面：`任务` -> `计划`
- 预期：点开任务 item 后显示轻量详情，其中 `AI 计划` 按钮进入带任务上下文的计划聊天页；快速捕获与深度规划保持分离。
- 实际：结构图中有子节点的节点仅切换展开 / 收起；叶子节点是静态展示。当前 app 源码没有 `AI 计划` 控件，也没有从任务节点调用计划工作区的路径。
- 复现：打开 `任务` -> 点按分支或叶子节点 -> 尝试找到详情和 `AI 计划`。
- 证据等级：B + C。UI 自动化确认节点点按只执行展开 / 收起；源码与全局检索确认入口缺失。
- 证据：`V2TasksView.swift:575-599,644-653`；spec `248-254,288,366-413`。
- 影响：`任务` 无法作为长期目标与 AI 规划之间的连接器，用户只能从无上下文的计划首页重新描述任务。

### P1-3 空状态无法启动未关联 Zen，也不能先搜索任务

- 页面：`今天`
- 预期：空状态可进入 Zen，随后搜索并关联任务，或不关联任何任务直接计时。
- 实际：空状态卡片只有说明文字，没有 Zen 入口。`startZen` 只由当前会话或时间线已有任务触发，因而不存在空状态搜索 / 不关联路径。
- 复现：在没有当前会话和今日任务时打开 `今天`，尝试直接进入 Zen。
- 证据等级：C，源码与 spec 审计。
- 证据：`V2TodayView.swift:32-63,447-465`；spec `113-121`。
- 影响：临时专注但尚未整理成任务的真实场景无法被记录，和轻助手定位不一致。

### P2-1 当前状态与开始 / 暂停控制仍被拆成两处

- 页面：`今天`
- 预期：进行中 / 暂停状态尽量由同一个开始 / 暂停控件表达，减少执行时阅读负担。
- 实际：焦点卡同时显示“正在发生 / 暂停中”状态胶囊，以及单独的暂停 / 继续图标按钮。
- 复现：开始一个今日任务，观察焦点卡顶部与底部操作区。
- 证据等级：C，源码与 spec 审计。
- 证据：`V2TodayView.swift:352-365,401-410`；spec `100-106`。
- 影响：不是功能阻断，但增加了用户在专注页面需要解析的状态元素。

### P2-2 回想页缺少“整理草稿”动作

- 页面：`回想`
- 预期：用户主动点击 `整理草稿` 后，AI 可依据当前日期与已选证据生成可编辑文字草稿；结果不自动保存，也不覆盖手写。
- 实际：底部只有 `引用` 与 `完成`；没有 `整理草稿` 入口或对应交互。
- 复现：打开 `回想`，检查文字和手写两种模式的操作栏。
- 证据等级：A + C。两种尺寸截图与源码审计一致。
- 证据：`V2RecallView.swift:418-444`；spec `431-438,474-479`。
- 影响：回想的基础写作可用，但 spec 中约定的主动 AI 辅助尚未交付。

### P2-3 今日快速插入不会识别输入中的时间

- 页面：`今天`
- 预期：普通输入成为今日任务；输入包含明确时间时，可成为今日该时间点的计划项。
- 实际：所有快速插入都保留完整输入为标题，并把计划项 `startAt` 固定为提交时刻，没有时间解析分支。
- 复现：在 `今天` 输入“下午三点交材料”并提交，检查生成计划项的时间。
- 证据等级：C，源码与 spec 审计。
- 证据：`V2Engine.swift:328-350`；spec `282-285`。
- 影响：自然语言捕获看似支持时间，实际安排位置可能错误；用户需要到时间视角再次手动整理。

### P2-4 Zen 全屏仍向辅助功能暴露底层今天页控件

- 页面：`今天` -> `Zen`
- 预期：进入全屏 Zen 后，VoiceOver 与 UI 自动化只访问 Zen 当前层的暂停、继续和结束控件。
- 实际：画面已经全屏，但辅助功能树同时存在 Zen 和底层今天页的两组“暂停”按钮；隔离验收断言期望 1 个，实际匹配到 2 个。
- 复现：新增并开始今日任务 -> 进入 `Zen` -> 检查辅助功能树中标签为“暂停”的按钮数量。
- 证据等级：B + C。隔离 UI 验收稳定复现；当前根视图使用 `fullScreenCover`，没有显式隐藏底层语义树。
- 证据：`V2RootView.swift:28-70`；`/private/tmp/tough-trial-user-journey-zen-accessibility.xcresult`。
- 影响：普通触控仍可完成 Zen 流程，但 VoiceOver 用户可能聚焦到不可见的底层控件，自动化也会遇到歧义。

### P3-1 任务地图默认取景缺少横向可探索提示

- 页面：`任务` -> `结构`
- 预期：默认聚焦当前分支，同时让用户理解右侧还有可拖动、可展开的细节。
- 实际：地图确实支持双向滚动、捏合缩放和按钮缩放；但两种尺寸首屏都让右侧后续节点直接延伸到屏外，且没有明显的横向可拖动提示。
- 复现：首次打开 `结构`，不操作地图，观察右侧分支。
- 证据等级：A + B。两种尺寸截图；展开 / 收起和缩放自动化通过。
- 影响：功能存在，但新用户可能把被裁切的内容理解成布局异常，而不是可探索画布。

## 已通过项目

- App 可启动，`今天 / 任务 / 计划 / 回想` 四个入口可达。
- `计划` 以独立全屏聊天工作区打开，内部不保留底部 Tab Bar，也没有全局加号。
- `计划` 默认是低约束聊天输入；AI 服务设置可打开，并明确显示关闭在线服务后使用“本地基础规划”。
- 今日快速新增在用户点击提交前不会写入任务，提交后才出现。
- 今天执行闭环可完成：新增、开始、暂停、继续、结束时间段、完成、恢复，并可从任务进入关联 Zen 后继续暂停、继续和结束。
- 今天允许两个任务并行处于活动状态；结束当前焦点后，另一个活动会话仍保留并可继续处理。
- 任务结构图支持多根上下文切换、双向滚动、捏合缩放、按钮缩放及节点展开 / 收起。
- 时间视角源码具备年、月、周、三日、日五种尺度；时间视角加号能在当前日期创建任务与计划项。
- 鱼骨视角使用单轴、完成节点和目标复选过滤，不展示百分比 dashboard。
- 回想进入时不自动弹键盘；主动选择文字后键盘出现；文字 / 手写在同一纸面原位切换，切换后文字草稿保留。
- 手写-only 回想可完成并显示已保存；手写文件采用本地原子写入。
- 回想包含日期轨道、全屏按钮、引用窗口和统一保存状态，没有顶部摘要或默认比例分析。
- 计划草稿的源码边界正确：`存草稿` 保存 pending draft，`加入计划` 才接受草稿并生成正式计划项。
- 本地基础规划的完整 UI 对话可走通：输入 -> 澄清 -> 生成草稿 -> 明确 `加入计划` -> 显示确认结果。
- 正常生产存储下，新建今日任务、回想文字和手写笔迹均能在 App 终止并重启后恢复。

### A. 模拟器 UI 实测与截图复核

- iPhone 17e，iOS 26.5：全套 `ToughTrialUITests`，8/8 通过，0 skipped。
- iPhone 17，iOS 26.5：代表性视觉基线与任务地图交互，2/2 通过。
- iPhone 17 首次全套运行曾被 XCTest 基础设施取消；重跑代表性用例成功，未将取消计为产品缺陷。
- 人工复核了两种尺寸的今天、任务、计划、回想首屏，以及任务树展开截图；未见标题、按钮、Tab Bar 互相遮挡。

## 尚未验证

- 正常生产存储下，计划项和回想引用关系跨 App 重启的 UI 级恢复。任务、回想文字和笔迹已通过补充 UI 验收。
- 长按加号语音输入、上拖锁定、系统权限拒绝与中断恢复。
- 真实 OpenAI-compatible 第三方服务连接、错误提示、超时、重试及返回结构兼容性。本次未持有可用测试凭据，也没有发起收费请求。
- 真机触感、Apple Pencil 自动切换、手指不误写、通知、Live Activity。
- VoiceOver 完整人工走查、超大 Dynamic Type、深色模式、横屏和低性能设备。Zen 的自动化辅助功能隔离已确认不通过，见 P2-4。

## 建议修复顺序

1. 补齐任务页当前上下文新增，让默认 `结构` 页的加号真正可用；鱼骨视角明确复用哪个 capture 上下文。
2. 增加统一的轻量任务详情，并从详情进入带任务上下文的 `AI 计划`。
3. 给今天空状态增加 Zen 入口，支持搜索关联或不关联任务。
4. 隔离 Zen 全屏下的底层辅助功能树，并合并今天焦点卡的状态和开始 / 暂停表达；把本次隔离执行闭环用例转为仓库正式测试。
5. 增加回想 `整理草稿`，保持用户主动、可编辑、未确认不保存的边界。
6. 补计划项与引用关系的生产存储重启测试、真实兼容 API 测试和真机专项验收。

## 验收决定

当前版本适合继续做内部手动体验，基础页面方向与视觉秩序已经成立；在 P1-1、P1-2、P1-3 修复并补齐主旅程验证前，不建议把它描述为“已按当前 spec 完整实现”。
