# 统一输入 B 批次验收（2026-09-11—12）

范围：今天、任务结构/鱼骨/时间、快速待办、已有任务编辑和助手待确认提案复用任务编辑能力；任务显式语音回填；助手同页展开长输入。分类/记账/联网仍属于后续批次。

## 设计与接线

- TaskEditor 管理独立标题/备注草稿、保存/取消、失败提示及未保存确认。TaskFields 复用原生多行输入和语音目标选择。
- 今天和时间新增传入备注，在创建任务/安排的同一事务中保存。今天仍进入当天；时间仍使用选定日期；任务结构保留父 ID；快速待办默认不排期。
- 助手提案编辑共享字段和编辑生命周期，日期通过组合字段保留；保存只修改提案，明确确认后才写任务。已保存任务的助手调整语义不变。
- 助手长输入使用同页展开的原生 TextEditor，小屏展开高度上限 190，提供 44 点触控区域的“收起键盘”按钮；引用、发送和排队仍使用原会话 Store。任务语音完成后只回填草稿；助手保留原来的“完成后交给 AI”。
- 根目录 `tasks/` 临时文件忽略规则改为 `/tasks/`，防止 macOS 将生产 `Components/Tasks` 一并忽略。
