# 当前 App 的网页交互评审

基准是当前 1.0（13）SwiftUI 实现，不是提前做的新设计。页面按 iPhone 13 Pro 的 390 × 844 pt 复刻，用户先在 Codex 网页标注，再根据意见调整正式 App。

## 本地交付

预览地址：http://127.0.0.1:8767/

运行入口：`outputs/app-ui-preview/server.py`。该目录保存私有任务副本，已由项目的 `outputs/` 忽略规则排除。服务只监听本机，不连接手机存储或第三方。

任务数据取自 9 月 14 日手机本地快照，只提取任务字段用于显示。预览中的编辑、完成和新增保存在浏览器副本，不标记手机上的反馈任务完成。AI、语音、通知、系统键盘与真实同步不在浏览器执行；页面提供预览说明。

## 复刻依据

- 通用外壳/样式：`V2RootView.swift`、`V2Theme.swift`。
- 任务四视图：`V2TasksView.swift`、`V2TaskTimeView.swift`。
- 连续编辑：`Components/Tasks/V2TaskEditor.swift`、`V2TaskFields.swift`。
- 其他主页面依据当前对应 SwiftUI 文件，所有预览代码与正式 iOS 代码隔离。

SF Symbols 用 SVG 近似、字体使用浏览器系统字体；iOS 玻璃材质、系统动效、原生键盘和手势无法承诺逐像素一致。当前范围是五个主页、任务四视图和常用弹窗，不是完整的跨平台 App。

## 标注

页面内“标注页面”可选中控件，记录页面、控件选择器、坐标、当前弹窗与滚动位置。批注支持定位、编辑、处理/重新打开、删除与 Markdown 导出，保存在 `outputs/app-ui-preview/feedback.json` 和 `feedback.md`。保留先前 8766 端口的旧截图评审与批注。

## 交付边界与剩余确认

- 本次没有修改或重装手机 App，也没有更改手机任务完成状态。
- 手机真实数据只复制了任务字段；其他页面是空态或可编辑的示例副本，不加载真实 AI 配置、密钥、助手历史、账单与执行数据。
- 五个主页、任务四视图和常用弹窗已复刻。AI 服务配置、文件选择、通知、GitHub 同步等系统入口使用明确说明，不代表完整功能复刻；Zen 仅为交互示例计时，不生成记录；财务统计仍未实现，没有混入预览。
- 原生 `confirm()` 在 Codex 浏览器重置预览时阻塞了输入。已将重置和批注删除改为页面内确认框，并通过 JS 语法检查。已打开新预览标签页；需用户关闭旧页原生弹窗后复核这两个确认框及干净副本重置。之前创建的 2 条验收任务仅在网页 localStorage 中，不在手机里。
- 标注新增/编辑/刷新恢复/定位（主页面）/处理/重新打开/删除原流程已验证；新确认框和详情弹窗的跨页面定位尚需浏览器恢复后的最后复核。

所有 4 个 JS 文件语法检查通过；批注 API 校验检查通过。UI 的图标和系统字体是近似实现，不能称为逐像素一致。
