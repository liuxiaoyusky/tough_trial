# 任务展示与创建速度更新

用户确认三项调整：统一今天的助手任务样式、集中展示零散任务、减少简单创建请求。

## 实现

- 今天复用原任务行，只在原卡片边框提示助手修改；不再给整行时间轴套 8 pt 蓝框。高亮 8 秒后经应用时钟刷新淡出，新修改重新计时，撤销即时清除；不改变任务本身。
- 结构入口为真实顶层任务列表，独立任务直接查看详情；有子任务的目标可打开原结构地图，支持缩放/折叠和返回列表。列表新增保持顶层，地图内新增仍属于当前目标。
- 简短明确的“新增任务：…”、“请帮我创建一个任务，…”直接进入现有日程模型；疑问、否定、条件、长输入走通用路由。快速路径只负责选择解析器，模型仍可追问。没有减少原子校验、确认、撤销、取消、会话隔离能力。
- 沿用用户保存的模型，不替换凭据或模型配置。本轮可证实的是请求次数从路由 + 日程两次降为日程一次，不能推断云端耗时固定减半。其他自然表达不保证进入快速路径。
