# 助手主页验收记录 · 2026-09-11

已构建版本：1.0 (5)，签名验证通过。本次为用户批准的助手主页路线 P0–P5 实施记录；不能把本地回归等同于真机或真实供应商验收。

## 已实现

- 助手默认首页，顺序为助手 / 今天 / 任务 / 随手记 / 回想。任务入口切换 Tab 并携带来源，来源卡片可返回对象；隐藏模块保留临时入口。
- 原生多行输入、内部滚动与展开编辑；按会话保存草稿；切页和切会话恢复草稿。保存做短延迟合并，不在每个按键重复生成会话日志。
- 双方消息支持复制、选择文字、引用；引用包含来源会话/消息 ID 与摘录，作为独立上下文送入模型，保留至会话文件。附件复用现有资产存储与 Quick Look；图片 OCR、文本和 PDF 可提取文字，不可读文件明确说明。
- 已保存的服务 / Coding Plan、模型、思考设置可按会话切换，或设为新会话默认；运行中的回合固定配置。聊天、计划、日程和动态日程工具保持同一配置，Trace 记录实际服务、模型和思考设置。
- 通用对话可直接回答；多工具链按回执继续。工作中可编辑、排队补充、撤回。明确修改仍直接执行并可撤销；无法由宿主确认的口语写请求先生成待人工确认的提案，问候/否定/讨论不能借旧上下文执行写入。此路径是有确认保护的语义提案，不是无限制自动写入。
- Compact 保留原始 JSONL、独立引用和来源。短会话、无收益、重复整理有不同反馈。指标使用与实际请求一致的 40 条 / 单条 4,000 字 / 总计 16,000 字的历史投影；比较范围是会话正文与摘要，token 明确为本地估算。旧回合重试不覆盖当前摘要。

## 供应商参数核验

- [GLM 思考模式](https://docs.bigmodel.cn/cn/guide/capabilities/thinking-mode)：GLM-5.3 与 Flash 强制思考，不能显示“关闭”。默认采用低强度；迁移旧的无效关闭配置。
- [GLM-5.3 官方模型卡](https://huggingface.co/zai-org/GLM-5.3)：low / high / max。GLM-5.2 不把映射到同一档位的 low / medium 伪装为独立能力。
- [Kimi API](https://platform.kimi.com/docs/api/chat)：仅对已核验的端点与模型显示强度选项；未核验的 Coding Plan 别名只显示自动。
- [MiniMax OpenAI 接口](https://platform.minimaxi.com/docs/api-reference/text-openai-api)：保留思考内容分离，不伪装存在可调强度。
- 思考与回答共用输出预算，避免沿用过小预算导致只有思考、没有可用 JSON 回复。尚未在本轮对真实供应商进行延迟/质量对比。
