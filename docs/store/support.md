# Tough Trial 支持

Tough Trial 帮助你安排今天、拆解长期目标并记录实际用时。App Store 首发提供今天、任务及日程同步，免费下载和使用。

## 常见问题

**如何开始？** 在“任务”或“今天”创建任务，然后开始计时。开始另一项任务时，前一项会暂停，避免重复计时。

**忘记暂停怎么办？** 打开任务详情的执行记录，修正实际开始或结束时间。保存前检查日期和时间，尤其是跨午夜的记录。

**如何同步两台设备？** 在“更多 → GitHub 同步”分别授权，两端选择相同的仓库、分支和日程文件。已有数据的设备首次合并前请查看合并内容，并保留备份。

**需要 AI 账号吗？** 不需要。App Store 首发不开放 AI 助手，核心任务与计时功能不需要外部 AI 服务。

**怎样反馈问题？** 请邮件说明应用版本、系统版本和复现步骤。截图请遮盖私人任务及账号信息；不要发送密码或密钥。
