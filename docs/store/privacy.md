# Tough Trial 隐私政策

生效日期：2026 年 10 月 23 日
发布者：dio
隐私与支持邮箱：sky.liu.xiji@gmail.com

本政策适用于 Tough Trial 的 App Store 首发版本。Mac 开发版与 TestFlight 测试版可能包含额外功能，不属于本政策所描述的首发功能范围。

## 本地数据

任务标题、正文、成长树、计划、执行时间、活动标签及应用设置默认保存在设备本地。应用不要求创建 Tough Trial 账户，不包含广告、广告追踪或第三方行为分析 SDK。首发不开放 AI 助手、云端转录或 AI 自动分类，不会向 AI 服务发送内容。

## 可选的文件与 GitHub 同步

你可以主动导出或读取日程文件。文件由你选择的存储位置及其服务商管理。

GitHub 同步是可选功能。连接时，你会在 GitHub 网页授权，然后选择或新建自己的私有仓库。应用读取你的 GitHub 账户标识及可写仓库列表；确认连接后，任务、计划、成长树结构、活动标签、执行记录及同步所需的版本信息会上传到所选仓库。后续可以自动同步。录音、视频及其他附件不会通过此日程协议上传。

GitHub 授权凭据保存在设备钥匙串中，不写入日程文件或源码。网页授权的 repo 权限范围大于单个仓库；本应用只将所选仓库用作同步目标。GitHub 会按照其[隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)处理授权、网络请求及仓库内容。开发者不运营接收日程内容的服务器，不自动获得你的私有仓库访问权。

## 系统服务

计划提醒和专注活动使用 Apple 的系统能力。系统备份及你选择的文件存储服务可能保存应用数据，具体由你的设备和服务设置决定。应用不会将数据用于跨应用广告跟踪。

## 保留、删除与控制

你可以编辑或删除任务、关闭同步，或在 GitHub 设置中撤销授权。停止同步或删除本机应用不会自动删除远端仓库、Git 历史或系统备份；如需完全移除，应同时管理相应仓库及备份。卸载应用通常会移除应用沙盒，但钥匙串凭据可能仍由系统保留；你可在 GitHub 撤销对应授权。

## 联系与变更

你主动发送支持邮件时，我们会收到你提供的邮箱和邮件内容，用于处理问题。请不要发送密码或 API 密钥。

隐私问题请联系 sky.liu.xiji@gmail.com。新增涉及数据处理的功能时，我们会同步更新政策及商店隐私说明。
