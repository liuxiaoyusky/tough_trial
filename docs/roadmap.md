## 当前结论

iOS 与 Mac 已具备较完整的本地功能，当前处于真实体验收尾与跨端能力补齐阶段。已实现不等于已完成真机验收；安装成功不等于全部功能通过；现有 GitHub 任务/日程同步不等于全量备份。

最近确认的手机版本是 TestFlight 1.0（17）。此前 1.0（16）包含目录 / 倒树双模式，安装启动成功，但定向真机交互被画中画浮窗遮挡；1.0（14）的 9 项设备状态/组件测试与 4 项 UI 测试在 9/21 复验通过。以上均为历史版本证据，不关闭 1.0（17）的当前体验验收。此前底栏失败未复现、根因未确认；自然输入、真实 AI 与完整导航等验收仍开放。重复规则目前仅完成设计。

9/30 远程安装：1.0（17）已通过 TestFlight 完成分发；用户于 19:16 确认在 iPhone 安装并打开。用户同时反馈实际页面与评审体验不一致，随手记截图出现浅色背景上的白色标题、分段文字低对比和灰色底栏。此视觉问题仍未修复，不把安装成功视为体验验收通过。见 [TestFlight 准备记录](qa/2026-09-30-testflight-preparation.md)。
